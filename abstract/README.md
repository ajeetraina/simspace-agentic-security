As agentic workflows give AI systems more autonomy to pull dependencies, build environments, and invoke tools, the security of your container foundation has never mattered more. This session puts security front and center. You'll start off with learning core security features, such as SBOMs, VEX, and the SLSA framework. From there, you'll learn about and get hands-on with Docker Hardened Images (DHI) and how they utilize these capabilities to give every developer and agent a safe baseline to build from. Finally, learn how to use build policies and image signing to safeguard your CI pipelines and deployment environments. Leave this session with a clear framework for securing your entire stack.
